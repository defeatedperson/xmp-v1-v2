PHP 8.4 镜像扩展说明
====================

本说明基于镜像 `defeatedperson/php:v8.4.0`，以及当前目录下的构建文件：

- Dockerfile: `d:\vue\xmp\php环境\Dockerfile`
- 配置文件: `d:\vue\xmp\api\data\appstore\php-versions.json`

目标：在基础镜像已经自带一部分扩展的前提下，Dockerfile 只额外安装缺失的扩展，同时在此列出最终构建成功后 PHP 中可用的主要扩展。

一、基础镜像自带扩展
--------------------

在不做任何额外安装时，基础镜像中已经包含以下扩展（来自 `phpinfo()` 输出）：

- Core
- date
- libxml
- openssl
- pcre
- sqlite3
- zlib
- ctype
- curl
- dom
- fileinfo

- readline
- Reflection
- Phar
- SimpleXML
- tokenizer
- xml
- xmlreader
- xmlwriter
- mysqlnd
- cgi-fcgi
- sodium
- Zend OPcache

以上扩展由官方 PHP 8.4 FPM Alpine 镜像自身提供，Dockerfile 不再重复编译。

二、通过 docker-php-ext-install 安装的扩展
----------------------------------------

当前 Dockerfile 中，使用 `docker-php-ext-install` 额外编译并安装的扩展为：

- sockets
- bcmath
- bz2
- exif
- gettext
- gd
- intl
- mysqli
- pdo_mysql
- zip

这些扩展在基础镜像中默认不存在或未启用，通过编译安装后，在 PHP 中会作为普通核心扩展存在（在 `php -m` 中可以看到）。

三、通过 PECL 安装的扩展
------------------------

通过 `pecl install` 安装的第三方扩展为：

- redis
- memcached
- imagick

PECL 安装完成后，这些扩展会以共享模块的形式加载，同样可以在 `php -m` 或 `phpinfo()` 中看到。

注意：

- 实际运行时，可以通过 `php -m` 或访问 `phpinfo()` 页面来确认扩展是否已经正确加载。
- `php-versions.json` 中的 `"extensions"` 列表描述了此运行环境中将提供的功能性扩展，其中：
  - `"mode": "core"` 表示扩展由基础镜像或 `docker-php-ext-install` 提供；
  - `"mode": "pecl"` 表示扩展通过 PECL 安装。
